# 平行·世界 | Parallel · World

> Mindustry 偏剧情模组 / Mindustry story‑focused content mod
> 最低游戏版本 / Minimum game version: **160.5**

---

## 📖 模组介绍｜Description
### 中文
平行宇宙时间线，我们Sharded远征至未知星球—地球。
我们的探测阵列发现地球，投放前卫站，由前卫者完成星球扫描。地表遍布远古文明遗迹。
勘探遭到本土防御集群拦截。我们原有工业体系无法适配此地环境，只能通过前卫者采集及观察敌方技术样本逆向研发，模仿本土防御集群的技术改造装备与生产线。

本土防御集群的来源存在多种猜想：Crux残存节点、Malis遗留部队，或是地球远古文明遗留的自动防御系统？

模组**不修改原版底层机制**，属于偏剧情向内容模组，并非完整战役剧情模组。新增独立科技树、星球—地球、战役地图、单位与炮塔，新增资源。剧情围绕对抗本土防御集群展开。一边搭建工业流水线，一边指挥单位推进，发掘这颗星球的秘密。

> ⚠️注意：**月球、零号区域完全尚未开始开发；地球本体以及配套科技树也才刚刚起步，大量内容还未完工。**

### English
Parallel‑universe timeline, the Sharded expedition travels to the unknown planet — Earth.
Our sensor arrays discover Earth and deploy the Forerunner Outpost, with Forerunners completing planetary scans. Ancient‑civilization ruins scatter across the surface.

Exploration is intercepted by native defense clusters. Our original industrial system cannot adapt to local conditions. We must collect and observe enemy technical samples via Forerunners for reverse‑engineering, imitating native‑defense‑cluster technology to refit equipment and production lines.

There are multiple hypotheses for the origin of native defense clusters: surviving Crux nodes, remnant Malis forces, or an ancient Earth‑civilization automatic‑defense system?

This mod **does not modify vanilla core mechanics**. It is a story‑focused content mod, not a full complete campaign mod. It adds an independent tech tree, new planet‑Earth, campaign maps, units, turrets and new resources. The plot revolves against native defense clusters. Build industrial chains, command units to advance, and uncover this planet's secrets.

> ⚠️ Note: **The Moon and Zone Zero have not been started at all. Earth and its corresponding tech‑tree are in early‑development stage; most content is still unfinished.**

## 🛠️ 安装方式 | Installation
### 方式1：Mindustry模组浏览器（推荐）
复制本GitHub仓库链接，在游戏内置模组浏览器导入，自动下载并安装。

### 方式2：手动本地安装
1. 下载仓库源代码 ZIP 压缩包；
2. 将ZIP压缩包直接放入 Mindustry 的 `mods` 文件夹；
3. **禁止解压ZIP压缩包**，重启游戏即可加载模组。

### Method1: Mod Browser (Recommended)
Copy this GitHub repository link, import within Mindustry built‑in mod browser for automatic download and installation.

### Method2: Manual local installation
1. Download repository source‑code ZIP archive.
2. Put the ZIP archive directly into Mindustry `mods` folder.
3. **DO NOT extract/unzip the archive**, restart the game to load mod.

## ⚠️ 已知问题｜Known Issues
### 中文
1. 独立科技树根节点英文翻译存在引擎限制：**模组热重载不会生效，必须完全关闭重启游戏才会切换显示**；中文不受该限制。
2. 月球、零号区域仅作为占位数据存在，**相关内容完全没有开始制作**。
3. 地球本体、地球配套科技树处于刚起步阶段，大量游戏内容尚未完工。

### Known Issues
1. Engine limitation for root tech‑tree title English translation: **Mod hot‑reload will not apply changes; full game restart is required**. Chinese display is unaffected.
2. The Moon and Zone Zero exist only as placeholder data, **no related content has been developed**.
3. Earth and its corresponding tech‑tree are just in early development; large amounts of gameplay content remain unfinished.
